Inviolable Covenant §1.0 Transparency

1. Zero Third-Party Trackers Commitment

In classical Islamic scholarship, the pursuit of sacred knowledge (Talib al-’Ilm) and the contemplative recitation of the Holy Qur'an require tranquility (Sakinah) and mental clarity. Modern web platforms frequently violate this contemplative space with invasive behavioral profiling, ad-tech tracking pixels, automated user categorization, and monetization funnels.

“To subject someone reciting the Word of God or studying a sacred Hadith to tracking pixels is a breach of spiritual hospitality and intellectual decency.”

Ruqyah operates under an uncompromising zero-surveillance covenant:

cancel What Ruqyah NEVER Runs
  • • No Google Analytics, Mixpanel, Amplitude, or telemetry pings

  • • No advertising cookies, conversion beacons, or fingerprinting scripts
  • • No session-recording software (Hotjar, FullStory, Clarity)

  • • Preferences and bookmarks reside 100% inside your local device sandbox

  • • Fully functional offline via Service Worker precaching
  • • Contact form dispatches directly via your native email client
  • • Full source code is publicly verifiable on GitHub under the MIT License
Storage Disclosure §2.0 Client Memory

To deliver a responsive, personalized experience—such as remembering your night reading theme, resuming a paused Surah recitation, or saving verse bookmarks—Ruqyah uses standard client-side web technologies: localStorage, sessionStorage, IndexedDB, and CacheStorage.

These values never leave your computer and are not transmitted to any application server. You hold 100% sovereignty over your data.

Network Architecture §3.0 Third-Party Endpoints

3. External Audio Hosts & Network CDNs

Ruqyah does not run proprietary tracking servers. When you navigate the site or play recitation streams, requests for static stylesheets, web fonts, and audio files are fetched from vetted third-party hosts.

Standard TCP/IP communication requires that these external providers receive ordinary network request metadata (your IP address, browser User-Agent header, and the requested file URL):

graphic_eq EveryAyah (everyayah.com)

Provides ayah-by-ayah MP3 recitation streams on-demand when you listen to individual verses in the 108 Master Verses Concordance. Requests are direct HTTPS GET queries with no authentication tokens or tracking cookies.

Protocol: HTTPS Cookie-free
album MP3Quran & QuranicAudio (mp3quran.net)

Delivers high-bitrate full Surah streams for the 114 Surahs recitation engine. Recitations feature esteemed Qaris including Sheikh Mishary Rashid Alafasy, Sheikh Abdul Basit, and Sheikh Mahmoud Khalil Al-Husary.

Protocol: HTTPS Streaming Audio
font_download Google Fonts (fonts.googleapis.com)

Serves web typography—primarily Inter, Amiri for classical Arabic calligraphy, and JetBrains Mono for code blocks. Requests are accelerated with preconnect non-blocking hints.

Protocol: HTTP/2+ Cached Edge
css Locally served Tailwind CSS bundle

Utility styles are compiled at build time and served by this website; visiting a page does not contact a Tailwind CSS CDN.

The bundle is served from this website and can be cached for offline use. No third-party request is made for these utility styles.

Protocol: HTTPS Static Engine
dns GitHub Pages (heynuo.github.io)

Hosts the static repository files directly from GitHub's global edge network over TLS 1.3 encryption. GitHub may collect aggregate infrastructure telemetry and server logs (such as visitor IP addresses) for DDoS mitigation, legal compliance, and network security pursuant to GitHub's Global Privacy Statement.

Encryption: TLS 1.3 / HSTS Global Anycast

Clarifications §7.0 FAQ

7. Frequently Asked Questions

Does Ruqyah set any HTTP tracking cookies? expand_more
No. Ruqyah does not set any first-party or third-party HTTP cookies. Preferences are stored exclusively using HTML5 localStorage inside your browser sandbox, which is never transmitted automatically in HTTP request headers.
Can Ruqyah see which Surahs I recite or what I search for? expand_more
No. Searching, filtering, verse concordances, and audio player progress are executed purely client-side using JavaScript. No logs or analytics pings are dispatched to Ruqyah.
What happens to my message if I submit the contact form? expand_more
The contact form does not submit to a remote server database. It drafts your text locally in your browser to prevent accidental data loss, then launches your computer or phone's default email client with a pre-formatted email addressed to the maintainer.
How does Ruqyah work offline? expand_more
Ruqyah installs a lightweight Service Worker (sw.js) that caches essential HTML, CSS, JavaScript, and Quranic text files in your browser's CacheStorage. This enables you to study verses and navigate the core site even without an internet connection.
How can I report a typo in an Arabic verse or English translation? expand_more
Textual fidelity is our highest priority. If you detect any typographical error, diacritical discrepancy, or translation nuance, please notify us immediately through the Contact Form or submit a pull request on the GitHub repository.
